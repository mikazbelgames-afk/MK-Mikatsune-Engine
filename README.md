# MK Mikatsune Engine v0.1

Base independiente para rig y animación ligera de Mikatsune.

## Incluye
- carga de piezas PNG/WebP
- posición, escala, rotación y pivote por capa
- roles para cuerpo, cabeza, orejas, ojos, boca, pata, cola y cristal
- idle base
- parpadeo de prueba
- guardar/cargar proyecto JSON
- runtime transparente separado (`runtime.html`)

## Próximo paso
Preparar la ilustración frontal de Mikatsune en piezas separadas y montar el rig. Después agregaremos timeline/keyframes, estados (follow/sub/bits/tip/chat) y la integración con StreamElements.
